# 原预算交付及 real 阻塞诊断实施说明

基点固定为 `2dde70ab203009afdb07e4337eb3cdd637906704`，独立分支 `refinement-budget-delivery`。本轮完整协议见 execution_guide.zh.md。旧归档 4253 个成员已恢复到 build/budget_delivery_restore 并逐成员核对 SHA；源模型仍为 convert 27、random 8、real 8。恢复收据、源输入/收据身份、旧文件保护清单、CPU/编译器与固定运行顺序均已登记。没有真实新采样或真实 solver check。

四配置由同一个新 worker 的启动参数冻结，显式拆分数值、等式验证、语法影响和评分策略。V0 保留 ValueCache 全行验证、传递变量集合及 affected 扫描；V1 只换稀疏验证；V2 再换池位集传播；V3 再加分组和事务评分。旧 Legacy/ValueCache/Shared 入口仍可调用。新的宿主生成树使用独立目录，环境参数 REFINEMENT_DELIVERY_CONFIGURATION 只在会话构造时读取；未设置时保持历史策略。原生 Ref、map、m_ls、RNG、后端、库与 65536 守卫不修改，B 不启用。

稀疏验证按旧变量和 incidence 行顺序执行相同的乘加、位长检查。一次分配行槽，用 epoch/touched 清理本次触及行；未触及的行与方向非零支持没有交集，其完整点积结构上恒为 0。完整 incidence 校验拒绝遗漏、重复、越界和零系数条目。所有已经验证的生成方向记录 component/local_id，入池后附 pool_id；省略或分量失败的方向不虚构稳定池号。独立 Python 从 AST 重建全部强制等式并重算全部行点积。

批量模式不建立传递变量集合或父边索引。池按旧顺序生成、交织、去重、截断、编号后，变量方向位集沿全 AST postorder 传播，包含共享 DAG、Bool、未选分支、x-x 和保留的原节点。按原 node ID 枚举置位方向，得到原序 affected。每节点使用四个 uint64_t 槽，实际 OR 只遍历有效字数。hard AST 使用自己的节点空间和变量映射，独立单方向语法传播计费；没有借主 AST 的 pool ID 查询硬条件。

评分索引用完整位集作为有序 map 键，精确相等，无哈希碰撞语义。分组最大权重、初始分数和零 covered 快照计入冷预处理。每事件从当前实际输出历史扫描原节点，汇总 changed covered bits，更新变化组对应的方向。单侧新增不扣分。scratch 状态完成并检查预算后 swap 发布；取消保留旧完整状态，下一次重新同步。公式指针、历史模式/会话和 version 一并核验；完整替换或下降历史重新建立权重，避免无符号下溢。L1/探针使用原生前缀，L2 使用实际交付历史。评分不访问 RNG 或原生状态。

FirstCovered 是明确的停止策略改变，四正式配置统一启用：第一个完整、非重复、保护通过且 covered 严格多于 native 的候选安全保存后停止。仅单侧增益不触发；AuditAll 探针及固定工作量等价测试关闭此停止。数值缓存、完整原式验证、官方观察、保护集合、原目标/参数顺序、64 次评价额度不改变。已经完成评价但在保存候选时取消，记录 evaluation_complete 与 incomplete_candidate，不能把它当作已经保存或交付。

预算 view 保留共同起始时刻，预处理算法软截止 96 ms、最终 100 ms；事件搜索软截止 18 ms、最终 20 ms，CPU 与墙钟分别判断。所有模型级保护、评分同步、缓存初始化、候选日志、序列化、写出和清理均由同一事件入口计量。完整 proposal 日志落盘后才暂定输出；交付 staging 复制/提交、旧账本释放、receipt 保存均为可选成本。外层及下一事件入口测量 postlude；晚超支就重建此前实际输出前缀、交付当前 native、作废评分状态。回滚本身的全部额外工作也计入可选累计成本。没有让超时替代的历史影响下一事件。

最后的时钟读数和字段写回不能自证硬实时。记录外层实际测得的 bookkeeping/postlude 与余量，边界余量不能覆盖该测量尾部时保守记 budget_eligibility_unknown 并回退。最终整条序列摘要的写出单列 summary tail，最后成本记录自己的不可自测尾部由父进程完整 CPU/墙钟补充，不能记作 0；报告单列进程未归属余额。没有借此证明历史逐模型 CPU 信用，historical_cpu_credit_proven 始终 false。

real 使用基点 ValueCache 数学实现和只读可选 sink，冻结原位置 2/3/4/5 各 16 原方向。证书按原 Bool 节点 DAG 共享，记录完整原子规范化常数/斜率、整数区间、floor/ceil/整除余数及 Bool 组合。语法不变公式记录精确 anchor 真值，其不变性由独立检查器重建。证书按序列化大小的 32 倍保守占用额度限制在 64 MiB；完整进程 RSS 另报，该额度不是精确堆使用测量。原域完成与完整解释完成分别记录。

real 的 128 条组合请求由旧 singleton-zero 证据排序确定，保存完整系数、anchor/AST SHA，不根据本轮耗时替换。只做 d_i+d_j、d_i-d_j、gcd/符号归一化，零/重复/原池重合保留，不补选。每个非零域只取绝对值最小、平局数值较小的一个非零点，再独立完整验证、官方观察、保护和评分；不做目标命中搜索，不注入正式历史。四个冷 worker 各遵守 2 秒预处理、8 秒原方向、8 秒组合及父进程 25 秒截止，原方向每条 500 ms、组合每条含归一化最多 250 ms。

独立检查器使用 Python 任意精度整数、自建仿射表达和规范化区间运算，重算原 AST 的完整 Bool 域，不调用 C++ LineDomain，也不以有限点采样替代区间证明。涉及不支持构造时不得算作 verified。阻塞摘要标明必需 AND 路径或条件结构，完整 DAG 才是 singleton-zero 证明；atom 摘要不称最小核。

合成测试保留了所有失败尝试：首次测试发现空组 ScoreSyncGroups 缺少入口取消检查，已补齐；另一失败是测试期望 JSON 把单个二元素数组构造成对象，已修正测试格式。两者均在真实探针之前。冻结的 +43 赋值只由测试审计器读取，生产选择器不读取实例名、输入 SHA、位置或已知方向/参数来选择快路径。

预冻结代码复核还修正了 epoch 回绕清理中途取消的恢复：清理未完成时保持 UINT32_MAX，下次先重做完整清理，再发布 epoch 1，避免旧 marks=1 冒充本次命中。稀疏行累加器和历史父边 scratch 均加入相同恢复测试。分量级取消另外保存 component/local_id，消元尚未产生方向时 local_id 明确为 -1。
