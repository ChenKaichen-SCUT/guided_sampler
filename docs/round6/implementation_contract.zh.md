# 第六轮实现契约（实现前）

从第五轮冻结源码建立独立Release/SAN树。唯一生产机制为可关闭的CCSS全局停滞守卫，65536原生步无严格全局best改善时正常返回Unknown。所有原生变量/move、初始化、map、RNG、重启、cutoff、成功恢复和正式接纳规则保持原路径。

源码已确认 update_best_solution 同时返回局部restart改善和全局改善；守卫必须独立检查严格全局下降。initialize会调用此函数，必须覆盖；首轮初始化前使用守卫自己的step=0，不能读取尚未赋值的原生_step。每次ls_sampling重置调用状态，内部initialize不重置历史。新增检查不得抢走零未满足的原生成功路径。

正式搜索热路径只有固定整数更新及判断。完整map、实际读集和RNG哈希只在调用/构造边界处理；每次CCSS都有精确退出步、全局best和退出原因。宿主截止与原生原因同时保留，不能用Unknown统称原因。重放成功仍仅为约简CCSS验证，不计正式模型。

正式G1/G2启动后不修改对应实现；工程构建/受控测试修复在冻结前进行并保留所有失败。后续只有G3允许的唯一候选可以产生新的冻结版本。全部阶段计时期间不编译、审计、压缩、上传。
