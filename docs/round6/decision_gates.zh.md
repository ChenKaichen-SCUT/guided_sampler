# 第六轮预注册判据

严格按附件执行，所有 seed=0。G1 固定六格只运行一次；G2 固定24个独立会话，分六批，每批四个不同物理核。固定顺序为 time120 三实例，然后 n20_t120 三实例，CPU配置轮换写入 config。日志与计分保留全部退出延迟，正式接纳不得超预算。不得把时间会话前20模型替代独立数量会话。

“显著回收”的局部定量条件预先固定为四个旧慢状态搜索墙钟均低于26秒（旧原生上限52秒）；同时要求真实宿主发生提前交还，且交还早于原生grant。实际有用还须至少一个匹配 time120 实例的后续CDCL数、正式不同模型数、官方covered均增加，并有交还后模型和正覆盖事件链。完整轨迹分叉后的差值不当作精确因果节省。

晋级核心对照为同构建RefG，指标为逐实例精确covered/total的百分点、等权平均。要求时间均值正、双方独立完成20模型的数量模式均值正、至少两个实例在这两个端点都严格正收益，严格20模型可比实例至少两个。这个保守解释防止用不同端点的单例胜利拼凑“两个改善”。缺少模型的实例不算平局或胜利。正确性、RNG和守卫有用条件必须通过；所有退步披露。G2已经达标时直接选FullG，不创造新算法。

G3先审计并提交结果再选择：正确性/快解失败或无时间回收则停止；供给改善但G1外质量损失使FullG不及RefG则只实现A；没有合法供给增加且存在相同实际消费map的连续停滞、两次之间没有新合法CDCL原始模型时才允许B；其他证据不足为No-Go。A从首次有覆盖历史后的第一项CDCL起固定Full/Ref交替，按查询推进，不能按触发或命中挑选。B若获准，跳过槽仍按原顺序生成一次原定seed，使跳过本身不偷改宿主抽样次数；不调用CCSS，跳过一次后清除冷却状态。

候选阶段所有三配置用同一新构建重新运行最多18会话。阈值65536、交替1:1不调参；不增加第三个候选。只有预登记晋级条件全部通过才启动32项F。F只运行RefG和Chosen；Chosen对FullG的新增机制消融来自开发阶段匹配对照，不追加未授权FullG正式矩阵。历史完整HighDiv只读，资源不完全配对的局限必须披露。
