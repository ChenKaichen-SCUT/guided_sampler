# Guided Sampler 第二轮 A-only 实现与实验报告

基点：`fc19bd22609295ed405e1ac96bf35d695c42832a`；分支：`round2-a-routing-repair`；冻结实现：`688e7d90a97952850a53b33053cd04b76c30fea4`。正式计划和依赖哈希见 [round2_a_plan.json](../manifests/round2_a_plan.json)。本轮仅运行 seed=0 的 8 实例 × 2 独立预算模式，共 16 项新 A-only 实验，全部完成并通过独立审计。未重跑 HighDiv，未追加 seed，未开启 B。

核心结果：实际相位改变 **534 次**，建议 916 次，涉及 414 个外层查询。最终覆盖相对冻结完整 HighDiv：time900 为 1 胜 / 5 平 / 2 负，n100_t900 为 3 胜 / 5 平 / 0 负。正式建议支持目标的新增 covered 为 **0**；独立模型核验发现 916 次建议的最终模型相位保留也为 **0**，内部 assignment 中 716 次保留不能当作模型命中。单 seed、历史基线与并发占用差异不支持宣称普遍优于完整 HighDiv。 本轮后端接入和软相位接口修复成立，但正式目标保持/访问机制仍不足，未证明相对完整 HighDiv 的总体性能改进。

## 软相位代码在哪里、怎样工作

相位仲裁在 [a_context.inc](../src/round2/a_context.inc) 的 `context::apply_A_phase_hint()`：保留已经选定的 `native_var`，先计算原生 `native_phase`，再以真实决策原子的规范键查当前单侧 bit 缺口；只将 `effective_phase` 设为建议相位。原生调用位置、`check()`、`setup_and_check()`、回溯与取消钩子见 [Z3 补丁](../patches/round2_a/z3.patch) 和 [补丁生成器](../scripts/patch_round2_z3.py)。

宿主 [AGuidanceBridge](../include/round2/a_guidance_bridge.hpp) 只在正式模型提交后，按 `Evaluation.changed` 更新索引。共享 query sidecar 经 combined solver 两个分支、goal 复制/翻译和 tactic 临时内核传递；普通决策窗口 64、建议额度 4、每个 Demand 每次查询至多一次。同相位也消耗建议额度。没有创建 B 编码、内部化 B、代理 literal、新断言或 relevance 标记，没有改变量选择、原路由、随机流或原生 CCSS。更详细边界见 [实现说明](A_soft_phase_guidance.zh.md)。

精确匹配支持结构相等、等式换边、NOT/原子极性、整数线性等价、严格与非严格比较。只承认原式显式等式为真时已知的整数值；等式为假不推导相反 bit。预处理改写产生而未证明等价的原子拒绝映射。没有域推断或为目标追加求解。正式改相位只在 convert 出现；其余七实例的覆盖差异不能归因于 A 相位指导。

## 只读失效分解、受控见证与测试

第一轮的证据分解先于修复完成，见 [诊断记录](../results/round2_a/diagnosis_before/root_cause_hypotheses.zh.md)。旧证据能区分未注册/未绑定/未使用，但不能恢复传播原因、真实窗口损失或最终访问；本轮没有把这些未知项解释为目标不可达。

Release 和 ASan/UBSan 均通过：观察器官方差分、模型投影、截止收据、有限解集、原生 off 轨迹与第一轮保存轨迹一致、observe/off 轨迹一致、正向覆盖命中、真实改相位后回溯放弃、两个 SMT 入口、goal 跨 manager 并行传递、窗口/配额、别名去重、零预算、暴露取消和 sticky fallback、清理后 SAT/UNSAT/CCSS、24 项上游 CCSS 测试。只保留原来精确定位的 32 字节上游泄漏例外，没有扩大抑制范围。证据见 [Release](../results/round2_a/correctness/release_final/summary.json) 和 [ASan/UBSan](../results/round2_a/correctness/sanitize_final/summary.json)。

固定 12 个历史快照 × off/observe/apply = 36 次机制对照已执行，每次原生 check 设置 2000ms 超时（并非硬墙钟截止，超时开销保留），无追加调用。结果见 [micro 表](../results/round2_a/micro/mechanism.csv) 和 [分析](../results/round2_a/micro/analysis.json)。全部 off/observe 原生轨迹的共同前缀一致；超时导致长度不同。历史模型与 assumptions 可重建，学习状态不可重建；机制对照与消毒器编译重叠，因此耗时不能充当性能证据。旧 8-bit 窗口比较只是 cursor=0 的明确反事实，实际历史 cursor 不可恢复。正式运行不执行窗口外扫描，潜在收益为 NA。

## 两个关键实例是否实际接入、为何没有收益

“接入”以实际叶子元数据与入口证据判定，不以外层注册成功代替。下列 SMT 查询数以查询 ID 去重；预处理已结束、纯 SAT、显式预算停用后均不计入支持数。

- SMT_random / time900：注册 308 次，实际 SMT 接入 308 个查询；叶子 `{"smt_tactic/setup_and_check": 308}`；改相位 0 次。前 64 次普通决策内映射 0 次，当前缺口 0 次，未映射 19712 次。
- SMT_real / time900：注册 1892 次，实际 SMT 接入 1891 个查询；叶子 `{"smt_tactic/setup_and_check": 1891}`；改相位 0 次。前 64 次普通决策内映射 0 次，当前缺口 0 次，未映射 121024 次。
- SMT_random / n100_t900：注册 100 次，实际 SMT 接入 100 个查询；叶子 `{"smt_tactic/setup_and_check": 100}`；改相位 0 次。前 64 次普通决策内映射 0 次，当前缺口 0 次，未映射 6400 次。
- SMT_real / n100_t900：注册 100 次，实际 SMT 接入 100 个查询；叶子 `{"smt_tactic/setup_and_check": 100}`；改相位 0 次。前 64 次普通决策内映射 0 次，当前缺口 0 次，未映射 6400 次。

未介入原因按查询、后端和决策层分别汇总于 [nontrigger_reasons.csv](../results/round2_a/analysis/nontrigger_reasons.csv)。SMT_real 时间模式的额外一次注册已进入 check（query 3780，剩余超时 29ms），在 solve-eqs 预处理阶段超时，尚未进入 SMT 叶子；不能归为 sidecar 接入失败。全目录 assigned/not-encountered 未测量项保留 NA。

完整 tactic 链保存在每项原始 `a_backend_calls.jsonl`。微测试可见 simplify/solve-eqs/lia2card/elim-uncnstr 等阶段后的原子；“未匹配”不等于“已消元”或“不可达”。绑定诊断仅检查前 128 个键、最多 1024 个变量和 10ms，未完成扫描标记 mapping_incomplete；传播或理论赋值原因未被可靠恢复时保留 unknown。

## 冻结、审计、归档与限制

16 个进程同一 barrier 起跑，8 物理核 / 16 逻辑槽位，完成的 n100 槽位不补任务。保留原协议并记录实际资源；第一轮基线是历史测量：原 64 项队列在 n100 槽空出后补入其他配置，本轮只有 16 项且空槽不补。高耗时实例的竞争负载因此不同，曲线不是严格同步配对。因此报告同时给精确覆盖、模型数和时间曲线，不进行统计显著性或普遍优势声明。

官方脚本未修改，版本与 SHA 固定在计划中。每个正式模型独立检查变量投影、去重、原公式合法性（官方求值及 Z3 完全替换化简）、正式收据与截止、官方百分比、在线/离线覆盖一致性；另有独立官方目标回放。全部 404895 个正式模型通过审计。完整审计见 [audit_summary.json](../results/round2_a/audit_summary.json)。

没有重跑 HighDiv 的证据：[BASELINE_UNCHANGED.json](../results/round2_a/BASELINE_UNCHANGED.json) 核验全部冻结产物哈希和 attempt 的 SHA/mtime；本轮调度器只接受新 Release 二进制及 a_only_v2 配置。离线审计曾因旧整理器内存增长中止，改为相同接纳规则的流式读取，已通过截止/损坏收据测试及字节一致对照；完成的有效审计保留，未重跑任何正式会话。中止记录见 `results/round2_a/audit_attempt_01.json`。第一轮归档引用基点 SHA；本轮新原始结果、所有失败/Unknown/未触发记录、构建与测试日志打包至 [archives/round2_a](../archives/round2_a/RESTORE.md)，每个分片与成员均校验 SHA-256。

仍未证明或无法恢复的事项：一般目标 Reach 的逻辑蕴含、预处理消元的完整反向证明、未知传播原因、超出正式 64 次窗口后的潜在机会、完整历史学习状态、全部历史影响的反事实成本，以及内部赋值与返回模型真值不一致的逐事件 relevance/理论原因。实现只给软相位建议，不保证可达、命中或提高最终覆盖。
