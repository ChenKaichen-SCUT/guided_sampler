# S 实现与验收口径

S 在 M 结果提交 f83f42b 之后实现。M 的头文件、构建树、二进制和原始会话保持冻结；S 使用 `include/round4/soft_reference` 与独立构建树。共同策略是采样器历史参考软化；S_ref 与 S_cov 只在覆盖优先级上不同。

`collect_inherited_reference()` 保留原宿主的声明筛选、模型遍历顺序、0.5 选择率及每个合格声明的一次原 RNG 抽取。只复制原声明的已定义精确值，不创建等式或常量应用。`QueryInputs::user_hard` 是独立的真实限制；只有这个向量进入 check。当前 CLI 没有额外外部 assumptions。每次选取记录源 CCSS 查询、原模型条目、声明身份、抽样值、RNG 状态摘要、参考与硬条件摘要。独立 RNG 重放器从 seed=0 重放选择与 CCSS seed 抽取。

`evaluate_reference_phase()` 读取已存在的原子，按类型和原声明身份查找部分参考。未知变量、内部 skolem、未支持运算或工作预算耗尽均回退未知；不补零、不调用求解器。整数计算精确；表达式深度、步数、时间和巨大数值受限，超限返回未知而不是截断。

`score_phase_evidence()` 对直接支持与确定相反位分别去重。`apply_S_phase_hint()` 是唯一 S 仲裁入口，接在正常原生选变量/猜相位之后。S_cov 按 `(support, -block)` 比较；平分或覆盖额度耗尽后使用参考，再回退原生。避免阻塞的目标掩码只取较差相位独有的直接阻塞，不声称选中相位保证期望位值或 Reach。

按用户明确答复，每次外层 check 最多 4 次覆盖建议，参考建议独立受前 64 次普通决策窗口约束。同一 canonical 原子、相位、目标和建议类别不重复覆盖引导；参考按同一 canonical 原子/相位去重。避免阻塞不写入全局“目标已尝试/实现”状态，另一原子的正向支持仍可使用同一目标。评分不因去重后无目标而反复改选次优相位，直接回退参考。

两类实际相位改变都开启同一 Run 的保守整查询暴露保护。参考收集、来源日志、登记、热回调、观察、结果诊断分别计账。暴露量不是因果新增开销。停用后不恢复此前学习状态。

S 不强制后端路由，不加入 dummy assumption、push/pop 或 solver1 开关；不改变 relevance、决策变量、CCSS、模型交换、模型恢复或正式接纳规则。内部 watcher 上限从旧诊断的 12 调整到 S 窗口所需的 64，事件缓冲仍有界；溢出保留 Unknown。实际赋值 token 来自 semantic events；历史 action.assignment_token 是首赋值序号，不能当作最终赋值 token 使用。

Release 测试中，纯评分对 `x=0` 和 `x=10` 的支持/避免方向正确，真实有限投影 0、1、2 均保留，联合不可行的位希望不变为硬约束。简单 `x=0 或 x=10` 的实际 SMT 选择是 `x>=10`：当前不增加域推理，因此覆盖机制未触发，两个模式都得到 0。这是受控接入负结果，不能把纯函数测试写成实际命中。布尔窗口测试实际产生 64 个参考/覆盖 action，S_cov 其中恰有 4 个覆盖建议压过参考。

正式结果必须使用共同的第三轮四目标清单与事前冻结的初始需求池比较。S_cov 自选目标的命中率只能作描述，不能与 S_ref 的零覆盖 action 分母直接相除，也不构成相同内部状态的因果对照。
