# 固定边界与失败保留

本轮从 `9270e83b7e95b9d9e51e0246de939d82ff570dce` 建立 `observation-preserving-refinement`，复用经第六轮验证的 65536 停滞守卫和完全相同的动态库。新增代码只在宿主交付层及纯整数模块；不改 Z3/CCSS 内核、交换策略、原生决策、B 或生产查询数。

原始第五轮 Ref 三条序列共有 43 个模型。原日志的 `queries.check_seconds`、提取及成本分类均为墙钟；`terminal.json` 的 user/system CPU 是整场总量。没有可分配到每个过去模型就绪位置的生成 CPU。不得把后续长调用 CPU、整场均摊或墙钟代替过去 CPU 信用。因此 L1/L2 只能给出固定 20/100 ms 上限、120 秒会话 5% 累计上限下的机会分析，不能证明在线双预算门槛通过。本轮不会用新性能队列补齐这项缺失。

官方冻结访问器并未实现 Bool ITE、XOR、蕴含、distinct、div/mod。语义域模块支持指南要求的布尔组合及不变非仿射项；正式观察器明确拒绝官方不支持的整体语法，不擅自扩大官方分母或返回零。真实三实例原语法属于官方支持范围。

预冻结失败全部保留：首次宿主构建漏复制冻结 include；第二次构建混用了不含第五轮偏好类型的头文件；已改为完整复制冻结宿主头文件。诊断 CLI 曾把临时赋值传给持引用的域对象，Release 检查与旧 ASan 构建均检出悬空引用；已保留具名赋值直到域对象销毁。一次取消/超时单元夹具被继承 watchdog 提前中断，无法到达拟测的交付边界；修正夹具先停止 watchdog 再精确注入交付取消/逾期，生产 watchdog 未变。任何失败都不与正式机会结果混拼。

数值循环及大整数操作合作检查预算。完整诊断 JSON 的最后一次编码/写入无法中断，实际耗时全部记入可选成本及超支；不声称硬实时。必需原生快照、原生反馈、独立输出账本及 prepare/commit/confirm 成本单列，仍属于完整会话时间。受控隔离夹具的 2000 次固定合成原生检查仅用于功能验证、提供真实已付生成信用，三模式完全一致，不属于生产代码或真实性能 seed。
