# 观察保留输出改进：实现、验证与限定实验报告

**结论：功能检查通过，本轮真实性能晋级为 No-Go。** 固定的 43 个第五轮 Ref 模型全部处理，40 个 L1 位置及主实现/component_only 两套 L2 均未产生完整候选评价或替换；输出覆盖完全等于原生序列。12 个固定 oracle 案例均在 3 秒总截止下结束，没有 SAT/UNSAT 答案。没有启动 24 次短会话或 32 项正式矩阵，没有重跑 HighDiv、追加 seed、启用 B 或调节冻结参数。工程正确性证据不能代替端到端收益。

基点为 `9270e83b7e95b9d9e51e0246de939d82ff570dce`，独立分支 `observation-preserving-refinement`。实现提交 `fccb363`，实现与离线输入冻结提交 `4b61386`；[完整实现清单](../../manifests/refinement/implementation.json)和[离线清单](../../manifests/refinement/offline.json)给出完整 SHA256。使用第五轮 Ref 原生策略，所有配置共享第六轮已验证的 65536 停滞守卫和原动态库。实际 HighDiv 宿主经独立树编译，头依赖、展开后的源文本、编译参数及 ldd 均保留。

## 1. 保护了什么，是否保护访问

保护集合是本次原生模型实际观察、而当前输出历史尚未观察到的全部 `(原始节点, bit, 侧值)`；含尚未 covered 的第一侧、常量、Bool 的 1 位及 Int 的低 64 位，负数按非负模解释。只有按冻结官方短路访问器实际访问的节点才有观察，不以表达式“有值”代替 Reach。候选必须保留整个集合；主排序为 `(新增 covered, 新增观察)`，相同分数输出原生。

实现位于 [observations.hpp](../../include/refinement/observations.hpp)、[history.hpp](../../include/refinement/history.hpp)、[refiner.hpp](../../include/refinement/refiner.hpp)。独立反例中，只看 covered 会接受一个增益从 2 增至 3、却丢失 5 个首次单侧观察的候选；完整保护将它拒绝。另有 y 值相同但 y 节点未访问的反例，以及共享 DAG、AND/OR/数值 ITE、NOT、负数与 bit 0/31/32/63 的官方轨迹对照。

冻结官方访问器不支持 Bool ITE、XOR、蕴含、distinct、div/mod；语义域支持与正式观察器支持分别记录，不扩展官方口径。三条真实序列的原语法可由冻结官方脚本评分。

## 2. 真实替代后是否污染原生状态

[宿主交付入口](../../src/refinement/session_commit.inc)先独立快照、验证并接纳原生模型，推进原生去重、计数和反馈；随后才选择输出。`num_samples` 来自原生接受数，数量预算来自及时确认的输出数。原始 `m_ls`、RNG、参考收集、CDCL→CCSS map 和 solver/model converter 路径不接收候选值。生产改进器不增加 solver.check、不创建约束、不替换决策变量。

Release 与 ASan/UBSan 的最终固定操作夹具各发生 **2 次严格覆盖增益替换**：第二个原生事件输出 `(x=1,y=3)`，第三个输出 `(x=2,y=16)`，原生 y 均为 0。每个版本仍为 4 个原生唯一模型、4 个正式输出。Off、Identity、Improve 的后续原生完整赋值、完整 mt19937 状态、m_ls 条目、参考与选择抽签、原生计数/反馈版本一致；两次 CCSS 的真实内部 map、R0/R1/R2/R3 和初始化值一致。不是把同 seed 当同内部状态。

这些夹具执行同样的 2000 次合成原生检查以取得已付生成信用，仅用于功能验证，不是生产新查询或性能样本。详细证据见 `correctness/isolation_{release,sanitize}_04/audit.json`，原记录在[完整归档](../../archives/refinement/RESTORE.md)。

## 3. 真实位置有多少预算内改进，失败在哪里

第五轮 Ref 的 convert 27、random 8、real 8 个模型均按原收据恢复；原节点编号与原始 DAG 逐项一致。没有筛选模型。L1 跳过每条首模型，共 40 个位置；两套 L2 各处理同一批 43 个原生模型。以下为 L2 主实现：

| 实例 | 原生/输出数 | 原生 covered / 总位数 | 输出 covered | 严格额外 covered | 主要退出原因 |
|---|---:|---:|---:|---:|---|
| convert | 27 / 27 | 36550 / 179302 | 36550 | 0 | 预处理超过 100 ms，关闭该序列改进 |
| SMT_random | 8 / 8 | 11230 / 104639 | 11230 | 0 | 超限等式分量被跳过，其他分量固定，方向池为空 |
| SMT_real | 8 / 8 | 5961 / 66061 | 5961 | 0 | 建成 177 个方向；事件在首个方向处理完成前耗尽 20 ms |

三种离线策略共 129 个含首模型事件，**完整候选评价 0、替换 0**。因此真实实例上“已证预算内合法改进”的数量为 0；这不是“满足保护的改进模型不存在”。尤其 random 的空池不能解释成整个数学系统没有自由度，real 的超时不能解释成域为空或目标不可达。

官方与独立覆盖逐项一致；全部已处理原生前缀的单侧及双侧观察包含通过。见[九条序列汇总](../../results/refinement/offline/frozen_v1/summary.csv)、[失败分类](../../results/refinement/analysis/final_v1/failure_reasons.json)。

## 4. 等式方向和跨 OR 有什么机会

精确有理消元、清分母、gcd 规范化后，每条方向独立验证所有必需等式的 `A*d=0`。只收集顶层递归 AND 下明确的仿射等式，不加入分支假设。固定分量限制为 64 变量/128 行/4096 非零项，未放宽。

合成例 `(x+y=15) AND (x=0 OR x=10)` 的域严格为 `{0,10}`，实际模命中函数提出 t=10；不要求经过非法的 1..9。真实三实例没有完成方向域和候选漏斗，主实现与 component_only 的输出一致，**本轮没有证明跨 OR 的实际收益**。real 的 177 条已生成方向说明方向存在，但不代表它们可在事件预算内完成合法域计算。没有完成域的方向不计作 unsupported 的实测比例；支持域比例本轮未能测得。

## 5. 保护拒绝了多少高分候选

真实实例完成评价的候选为 0，因此记录到的高分保护拒绝也是 0；无保护离线选择同样没有候选。不能据此认为保护条件宽松，不能将失败归因于保护过强。合成反例已验证保护确实能拒绝“分数更高却丢失原生首次观察”的候选。

## 6. 严格 covered、单侧观察与分区

真实序列严格额外 covered 替换 0，仅新增单侧观察替换 0。G1/G2/G3 使用共同首模型和第五轮冻结映射 catalog：G1 是首模型已访问且已记录映射的位，G2 是其余已访问位，G3 是未访问位。G2 不代表永不可映射。

| 实例 | G1 大小 | G2 大小 | G3 大小 | 各组 gain / loss / net |
|---|---:|---:|---:|---|
| convert | 24244 | 154958 | 100 | 全为 0 / 0 / 0 |
| SMT_random | 36623 | 66644 | 1372 | 全为 0 / 0 / 0 |

分区大小加总等于全式分母，净差加总等于全式差，见[完整分区表](../../results/refinement/offline/frozen_v1/partitions.csv)。

## 7. 全部成本与 oracle 能支持什么

L2 主实现成本如下，单位 ms。阶段成本包含未成功的预处理、事件及事件 JSON 编码。完整重放进程另包含输入读取、必需原生观察、最终结果封装和管道输出，全部保留，不拿阶段小计冒充完整成本。

| 实例 | 预处理 CPU / 墙钟 | 可选阶段累计 CPU / 墙钟 | 完整离线进程 CPU / 墙钟 |
|---|---:|---:|---:|
| convert | 101.014 / 101.424 | 101.014 / 101.424 | 381.8 / 442.0 |
| SMT_random | 11.061 / 11.094 | 26.712 / 26.782 | 88.3 / 137.7 |
| SMT_real | 35.017 / 35.133 | 176.170 / 176.560 | 220.5 / 286.5 |

没有真实成功改进，“每次成功的全成本”无定义。convert 预处理的合作取消存在约 1.4 ms 墙钟超支；real 事件取消后的日志/收尾超支也原样保留，不声称硬实时。所有完整离线进程均小于 6 秒绝对上限，但这不能证明按过去原生成本挣得的双预算通过。

**旧日志缺项：** 只有整场 user/system CPU；查询与提取日志是墙钟，无法确定每个过去模型就绪前的原生 CPU。不能用整场平均、后续耗时或墙钟代替。最终离线结果封装成本没有逐事件分摊，完整进程 CPU/墙钟提供保守总成本边界；未完成方向的具体在途记录未落盘，只保留事件取消、完整耗时和阶段余项。报告不把这些缺记录解释为算法无解。详见[记录边界](../../results/refinement/analysis/final_v1/record_boundaries.json)和[成本表](../../results/refinement/analysis/final_v1/costs.csv)。

固定 oracle 为每实例位置 2/3/4/5，共 12 案，冷启动、最多一次 check、check 上限 2 秒、整案 3 秒，无重试。编码包含完整 Reach、protected 及严格额外 covered 的全部目标，150 个独立穷举点已验证编码语义。实际 12 案全为 `oracle_case_external_timeout`，没有完整答案或模型；均未出现必须先于 check 写出的检查点。原始 `checks:null` 保留，按程序顺序可推导检查启动前中断，但不把推导伪装成原始计数。SAT=0、UNSAT=0、完整 solver Unknown 答案=0、外部截止未完成=12。外部截止后的实测进程墙钟为 3.009–3.015 秒、CPU 为 2.869–2.887 秒，退出延迟未扣除。共同成功案例=0，因此完全不支持“比重新求解便宜五倍”等描述，也不将超时当求解成功耗时。见[逐案对照](../../results/refinement/oracle/frozen_v1/comparison.csv)。

受控 Release 替换夹具的可选总成本为 CPU 2.361 ms / 墙钟 5.733 ms，必需交付成本 CPU 1.985 ms / 墙钟 13.662 ms，0 次原生就绪后逾期。这只是合成功能夹具，不能代替真实实例速度结论。

## 8. 是否减少原生生成机会，是否错过截止

没有进入真实在线对照，无法估计同墙钟下少生成了多少原生模型。离线重放不能拼接成实测在线曲线。受控真实替换测试中后续原生状态一致，且没有就绪后逾期；取消、写入失败和逾期夹具则正确保持输出数为 0。真实在线逾期率未知，不填为 0。

## 9. 等时间与等样本优势是否同时成立

没有成立的证据。在线等时间、独立 n20、独立 n100 比较集合均为空；没有在线均值、胜率或 AUC。离线同序列 27/8/8 个输出与原生相等，只证明这批输入上的观察保留，没有性能优势。

## 10. 哪条门槛失败

离线门槛 1 的功能/保护/状态隔离检查通过，门槛 4 未通过多输出或忽略 Reach 虚增收益。**门槛 2 失败：正增益实例数为 0，要求至少 2。门槛 3 未满足：没有实际成功改进，且历史过去 CPU 信用缺失。** [gate.json](../../results/refinement/offline/frozen_v1/gate.json)明确 No-Go。24 次短会话和 32 项正式矩阵属于未获晋级而未执行的阶段，不是待补的正结果。

## 11. 对 Ref、Full、完整 HighDiv 的结论范围

对冻结 Ref 的三条既有序列，变换后输出完全相同。对新宿主的 Ref/Full，固定操作关闭回归与第五轮保存的原生模型、决策及 RNG 记录一致，没有为比较启动旧二进制。**没有证据优于 Ref、Full 或冻结完整 HighDiv。** 完整 HighDiv 的历史成绩未重跑，也不拿离线局部成本替代与它的公平预算比较。

## 12. 已证明、有限实测与未知

在候选或原生回退及时提交的同序列处理中，完整保护给出逐前缀包含，并在本轮全部 129 个离线事件核验；它不能保证逾期/取消时仍能交付相同数量，也不保证等时间收益。Release 与 ASan/UBSan 各通过 244612 个算术案例、1356 个模命中案例、7938 个域参数点、4 类方向系统、32 个官方观察轨迹对照；另有原变量独立补全、实际 converter、真实替换隔离、独立去重、预算/取消、每个收据前缀截断重放及 Ref/Full 关闭回归。没有扩大既有上游泄漏抑制。

预冻结编译失败、CLI 临时对象悬空引用及其 ASan 报告、边界夹具被 watchdog 提前中断、未触发替换的小例子均保留；修复后重新验证，均发生在真实固定离线执行之前。当前冻结果未因不理想而重跑。

未知项包括真实预算内可行改进是否存在、跨 OR 能否兑现、oracle 对完整问题的答案、等时间原生机会损失及任何整体优越性。首要后续单因素候选是**缓存一维域中的不变子项精确值，减少重复整棵 AST 分配/扫描**，保持当前保护、配额、分量限制及预算不变；这是基于代码路径的工程推断，尚未验证，未在本轮实施。
