# 本轮实现契约（实验前冻结）

独立分支从第六轮交付 `9270e83b7e95b9d9e51e0246de939d82ff570dce` 建立。生成器为第五轮 Ref；共同启用第六轮已验证的 65536 步全局停滞守卫。依据是第六轮 G0/G1 正确性与快解保留，以及 G2 convert 的真实后续模型和覆盖产出；不是依据第六轮相对完整 HighDiv 的优势（该优势不存在）。所有当前配置保持同一守卫，不追加第六轮矩阵。

全部参数、限定尝试数、种子和门槛见 configs/refinement.json 与原始执行指引。完整 HighDiv 仅使用历史冻结结果。当前原式解析、原生模型恢复和相位机制保留；新增纯数值改进器只选择正式交付的完整原变量赋值。

Native 的 unique/count、coverage、guidance->formal_record/commit、pending_outcomes 与宿主 num_samples 均按原生模型推进；Output 独立维护去重、观察历史、正式收据和数量停止。m_ls、last_CDCL_model、参考来源、随机流及生产 solver 不接收替代值。测试必须包含实际替代之后的后续模型与完整原生状态记录，不能只证明 Identity。

新增观察包括官方实际访问节点的单侧 0/1；未访问不产生观察，NOT 独立，Int 采用数学整数的非负模 2^64。保护按每次当前输出历史重新计算。相同原生序列的已完成前缀逐侧包含是必须验证的性质，不外推为独立墙钟运行必胜。

冻结官方脚本的实际支持范围优先于想象中的完整 SMT 运算支持：例如它支持整数 ITE 的短路，但 _build_bool 不支持布尔 ITE/XOR/IMPLIES/distinct。数值合法性与一维域支持这些布尔运算；官方观察遇到不支持的原式则明确拒绝/停用改进，不悄悄改变计分语义。对应正确性测试分别验证域语义及官方不支持状态，不将扩展观察当成官方成绩。

新增仿射索引、等式方向和依赖索引在获得原生 CPU/墙钟信用后惰性准备，100ms 上限；每事件20ms，累计同时受5%会话绝对余额及10%已付原生生成信用约束。全部实际费用计入端到端时间，必需交付费用与可选改进费用分别记录。旧记录如缺逐模型原生 CPU，不能用总会话 CPU 或未来失败时间填补当前信用；这会限制离线晋级证据，必须原样报告。

仅正确性错误可以修复；保留失败尝试，废止受影响阶段并重新冻结。不重跑正确但收益不佳的实验。离线门槛失败即完成负结果交付，不启动短会话；短会话失败不启动正式矩阵。
